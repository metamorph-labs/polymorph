# Iconography — the semantic role vocabulary

**Map:** [`icons.json`](./icons.json) is the committed decision.
`packages/react/src/icon/map.tsx` transcribes it to lucide's glyph data and draws a glyph with
`GlyphSvg`. `<Icon>` (`packages/react/src/icon/Icon.tsx`) takes a role name and renders it.

Icons are two owned decisions (`docs/theming.md`). The **set** is lucide: one grid, one
stroke discipline, and mixing sets is a violation. The **assignment** means application code
and vocabulary components reference *meanings*, never glyph names. `<Icon name="delete" />`
keeps working through a change of glyph, or of the whole set, with no call-site changes, and
an invented icon name is a type error.

## The vocabulary — 108 roles, 5 groups

The closed enum in `icons.json`. Beside it, `trailing` lists the roles that may follow a label
(rule 7 below). Each entry is `roles.<role> = { glyph, group, ios }`, where
`glyph` is the lucide kebab name and `ios` the SF Symbol that draws the same meaning on Apple
platforms (`PMIconRole.systemName`, generated by `pnpm native:contracts`). Groups exist only for
documentation and gallery order. They are not API.

- **action (42):** add · remove · delete · edit · duplicate · copy · search · filter ·
  sort · sort-asc · sort-desc · refresh · rotate · flip · download · upload · share ·
  open-external · settings · overflow · link · run · pause · undo · connect · click ·
  send · stop · attach · record · helpful · unhelpful · redo · bold · italic ·
  strikethrough · code · heading · list-bulleted · list-numbered · quote · code-block
- **navigation (11):** back · forward · up · down · previous · next · expand ·
  collapse · home · menu · close
- **status (18):** info · success · warning · error · help · loading · locked ·
  unlocked · visible · hidden · favorite · pinned · notification · egress · denied ·
  local · watch · signin
- **object (29):** user · team · calendar · time · document · folder · tag · inbox ·
  archive · comment · table *(also `ChartTwin`'s toggle)* ·
  mail · device · model · terminal · key · network · cloud · tool · ledger · droplet ·
  briefing · kernel · diff · browser · delivery · reasoning · cite · artifact
- **form (8):** confirm · indeterminate · clear · drag · mode-light · mode-dark ·
  mode-system · rating

**The agent-runtime roles**: twenty for applications that run work on the user's behalf.
Four verbs such a runtime uses constantly (`run`, `pause`, `undo`, `connect`), the three
states an egress log reports (`egress`: something left; `denied`: something tried; `local`:
it ran here), and thirteen nouns of a personal runtime. `droplet` is the one mark-shaped role
(the `dew` system's emblem, `design/systems/dew.md`). It enters the same way as every other
role (rule 6 below), not as an inline `<svg>` in app code.

**The conversation roles**: nine for the `ai` tier (`docs/conversation.md`). Six verbs
(`send`, `stop`, `attach`, `record`, `helpful`, `unhelpful`) and three nouns (`reasoning`: the model's
thinking; `cite`: the source a sentence relies on; `artifact`: the pane beside the thread).
`stop` is a plain square, not a circled one, because it sits inside a Button that already
draws the frame. `record` starts a recording of the reader's voice, and its glyph is a
microphone, because a composer's voice input is drawn as one in every platform's own apps.

**The rich-text roles**: ten for RichTextInput's toolbar. `redo` pairs with `undo`, and
the other nine are the formats a document holds (`bold`, `italic`, `strikethrough`, `code`,
`heading`, `list-bulleted`, `list-numbered`, `quote`, `code-block`). `link` is the existing
role. `quote` formats a block as a quotation and draws lucide's `text-quote`; `cite` is the
source a sentence relies on and keeps its own `quote` glyph, so the two meanings do not share a
drawing on the web. On Android both draw `format_quote`, which Material Symbols has one of.

Deliberate indirections that exercise the layer:

- `close` (dismiss a surface) and `clear` (empty a value) currently share the `x` glyph.
  They are distinct decisions and can diverge without touching a call site.
- `remove` (take away from a collection) and `indeterminate` (mixed checkbox) share
  `minus` in the same way.
- `rotate` (turn the thing itself, as in ImageEditor's quarter turn) and
  `refresh` (fetch it again) share `rotate-cw` in the same way.
- `favorite` (a thing marked to keep) and `rating` (one mark of a score, as Rating draws
  it) share `star` in the same way.
- `duplicate` (make another) is **not** `copy` (to clipboard). They use distinct glyphs.
- Arrow glyphs appear under both sorting (`sort-asc`) and navigation (`up`) roles. The
  meaning, not the arrow, is the API.

**Glyph identifiers follow lucide's canonical names.** When lucide renames a glyph
(`filter` → `funnel`, `circle-help` → `circle-question-mark`), `icons.json` and the map move
to the new name. The map test (`packages/react/src/icon/map.test.ts`) looks up lucide's export
under the name `icons.json` gives and requires the map's entry to be that glyph, so a role
pointing at the wrong drawing fails the test instead of only looking wrong in a gallery. The
roles (`filter`, `help`) do not change, so no call site does.

## Rules (law, not guidance)

1. Only `packages/react/src/icon/map.tsx` (and its test) may import the icon set,
   `lucide` (the `polymorph/no-external-icons` red rule, `docs/rules.md`). The package
   provides glyph data, not components: the map draws each glyph's SVG elements itself, so
   no icon library runs in the application. Everything else, vocabulary and app code alike,
   uses `<Icon>`.
2. Icons never set their own colour: always `currentColor`. A status icon gets its colour
   from text carrying that status role (e.g. Toast title row in `--pm-danger-text`).
3. Sizes come only from `--pm-icon-size-sm|md|lg`, derived to match the text scale's line
   heights (14/16/20 at base). No other sizes exist. A hero illustration is `<Bespoke>`.
4. Stroke width comes only from `--pm-icon-stroke-sm|md|lg`. The tuning is one number per
   derivation: the type personality's base stroke plus the contrast temperament's delta
   (soft −0.25, stark +0.25; terminal, for instance, is mono 1.5 + 0.25 stark = **1.75**).
   It sets the weight an **md** icon draws. The per-size tokens compensate for each size's
   rendered box. SVG units are on lucide's 24 grid, so one number used at all three sizes
   would draw three different weights (sm at ~85% of md's line, lg at ~125%). With the
   compensation every size draws the tuned weight, the same optical sizing the type scale
   applies. `--pm-icon-stroke` is still emitted as the md anchor for component CSS that
   has not adopted the per-size split.
5. Meaningful icons carry `label` (renders `role="img"` + `aria-label`). Decorative
   icons are `aria-hidden`. An icon-only Button takes its accessible name from the
   Button's `label` prop instead (see `components/button.md`).
6. Custom or brand glyphs enter only through normalization (24×24 viewBox, stroke from
   token, `currentColor`) and only by adding a **role**. App code never uses inline `<svg>`
   (`polymorph/no-external-icons` reports it; only the chart tier draws SVG).

7. An icon leads its text. The roles that may trail it point onward or show a disclosure, and
   `icons.json` lists them as `trailing`: `forward`, `next`, `down`, `expand`, `collapse`
   and `open-external`. A back arrow leads. `polymorph/trailing-icon` holds a Button's
   `trailingIcon` to the list, and so does the validation a screen spec gets.

## Adding a role (the cheap promotion path)

One line in `icons.json` (plus its transcription in `map.tsx`) with a one-word meaning, a group and
its SF Symbol; then `pnpm native:contracts`. If the meaning duplicates an existing role, use the
existing role. Renames are breaking changes and go through deprecate-with-sunset (the change
protocol, `docs/concepts.md`).

## Reduced-motion / temperament note

`loading` is the only role with intrinsic motion (`spin` pattern, ambient). At
`data-motion="none"` or `prefers-reduced-motion` it renders static. The state stays
legible because the glyph itself and `aria-busy` carry the meaning (no state is legible
only through its transition, `docs/motion.md`).
