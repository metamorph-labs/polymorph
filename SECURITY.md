# Security

## Reporting a vulnerability

Please report security issues privately, through GitHub: on this repository, open
**Security → Report a vulnerability**. Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and which package and version it affects. We will
acknowledge the report, keep you informed while we fix it, and credit you in the release notes
unless you prefer otherwise.

## Supported versions

Fixes land in the latest release of each package. Polymorph follows semantic versioning; a fix
that needs a breaking change is released as a major version.
