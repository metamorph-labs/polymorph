# Code of conduct

Polymorph follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone taking part — in issues, pull requests, discussions and any other project space — is
expected to uphold it.

To report unacceptable behaviour, contact a maintainer of the
[metamorph-labs](https://github.com/metamorph-labs) organisation privately. Reports are handled
confidentially, and the maintainers will respond as the Covenant's enforcement guidelines describe.
